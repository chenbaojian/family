### 1.2 请求处理流程

```
用户操作 → Vue组件 → API调用 → Axios请求 
    → Express路由 → 认证中间件 → 控制器 → 模型 → 数据库
    → 返回响应 → Vue组件更新
```

## 二、用户认证模块

### 2.1 用户注册流程

```
┌──────────────────────────────────────────────────────────────────────────┐
│                            用户注册流程                                   │
└──────────────────────────────────────────────────────────────────────────┘

用户操作                    前端处理                      后端处理
   │                          │                            │
   │  1. 填写注册表单          │                            │
   │  (用户名、密码、邮箱)     │                            │
   │ ──────────────────────►  │                            │
   │                          │                            │
   │                          │  2. 调用register()         │
   │                          │  (api/auth.js)             │
   │                          │ ─────────────────────────► │
   │                          │                            │
   │                          │                            │  3. POST /api/auth/register
   │                          │                            │     │
   │                          │                            │     ├─ 验证必填字段
   │                          │                            │     │
   │                          │                            │     ├─ 检查用户名是否存在
   │                          │                            │     │  User.findByUsername()
   │                          │                            │     │
   │                          │                            │     ├─ 密码加密(bcrypt)
   │                          │                            │     │
   │                          │                            │     ├─ 创建用户
   │                          │                            │     │  User.create()
   │                          │                            │     │  (status='pending')
   │                          │                            │     │
   │                          │                            │     └─ 返回成功响应
   │                          │                            │
   │                          │  4. 显示注册成功提示        │
   │  5. 提示等待审核          │ ◄───────────────────────── │
   │ ◄──────────────────────  │                            │
   │                          │                            │
```

**涉及文件：**
- 前端：`views/Register.vue` → `api/auth.js` → `utils/request.js`
- 后端：`routes/auth.js` → `controllers/authController.js` → `models/User.js`

**API接口：**
```
POST /api/auth/register
请求体: { username, password, email, phone }
响应: { success: true, message: '注册成功，请等待管理员审核' }
```

### 2.2 用户登录流程

```
┌──────────────────────────────────────────────────────────────────────────┐
│                            用户登录流程                                   │
└──────────────────────────────────────────────────────────────────────────┘

用户操作                    前端处理                      后端处理
   │                          │                            │
   │  1. 输入用户名和密码      │                            │
   │ ──────────────────────►  │                            │
   │                          │                            │
   │                          │  2. 调用login()            │
   │                          │  (api/auth.js)             │
   │                          │ ─────────────────────────► │
   │                          │                            │
   │                          │                            │  3. POST /api/auth/login
   │                          │                            │     │
   │                          │                            │     ├─ 验证必填字段
   │                          │                            │     │
   │                          │                            │     ├─ 查找用户
   │                          │                            │     │  User.findByUsername()
   │                          │                            │     │
   │                          │                            │     ├─ 验证密码(bcrypt.compare)
   │                          │                            │     │
   │                          │                            │     ├─ 检查用户状态
   │                          │                            │     │  ├─ pending: 返回403
   │                          │                            │     │  ├─ disabled: 返回403
   │                          │                            │     │  └─ active: 继续
   │                          │                            │     │
   │                          │                            │     ├─ 生成JWT Token
   │                          │                            │     │  generateToken()
   │                          │                            │     │
   │                          │                            │     └─ 返回Token和用户信息
   │                          │                            │
   │                          │  4. 存储Token到localStorage │
   │                          │  localStorage.setItem()     │
   │                          │                            │
   │  5. 跳转到首页            │  5. 路由跳转               │
   │ ◄──────────────────────  │  router.push('/')         │
   │                          │                            │
```

**涉及文件：**
- 前端：`views/Login.vue` → `api/auth.js` → `utils/request.js`
- 后端：`routes/auth.js` → `controllers/authController.js` → `utils/jwt.js`

**API接口：**
```
POST /api/auth/login
请求体: { username, password }
响应: { 
  success: true, 
  data: { 
    token: 'JWT Token', 
    user: { id, username, email, phone, role } 
  } 
}
```

### 2.4 修改密码流程

```
用户操作                    前端处理                      后端处理
   │                          │                            │
   │  1. 输入旧密码和新密码    │                            │
   │ ──────────────────────►  │                            │
   │                          │                            │
   │                          │  2. 调用changePassword()   │
   │                          │ ─────────────────────────► │
   │                          │                            │
   │                          │                            │  3. PUT /api/auth/password
   │                          │                            │     │

   │                          │                            │     │

```

### 4.4 删除成员流程

```
┌──────────────────────────────────────────────────────────────────────────┐
│                           删除成员流程                                    │
└──────────────────────────────────────────────────────────────────────────┘

用户操作                    前端处理                      后端处理
   │                          │                            │

   │                          │ ─────────────────────────► │
   │                          │                            │
   │                          │                            │  3. DELETE /api/members/:id
   │                          │                            │     │
   │                          │                            │     ├─ 认证中间件
   │                          │                            │     │
   │                          │                            │     ├─ 角色检查('admin')
```

## 十、总结

本系统采用经典的三层架构设计：

1. **前端层**：Vue 3 + Element Plus，负责用户界面展示和交互
2. **后端层**：Node.js + Express，负责业务逻辑处理和API服务
3. **数据层**：MySQL，负责数据持久化存储

系统通过JWT实现用户认证，通过角色机制实现权限控制，确保不同角色用户只能访问其权限范围内的功能。所有API请求都经过统一的认证中间件验证，保证了系统的安全性。
